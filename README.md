E is a high-level, interpreted programming language featuring an explicit syntax, a custom dot-notation mathematical processing engine, dynamic type-safe inputs, and a robust error-handling core.

## 💻 How to Run E Scripts on a Mac
To run an `.e` program file, download `interpreter.py` and execute it through your terminal using Python 3:

bash
python3 interpreter.py app.e
